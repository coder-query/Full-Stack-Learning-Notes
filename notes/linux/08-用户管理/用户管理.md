| 系统区别     | Linux | windows       |
| ------------ | ----- | ------------- |

## 2，UID和GID

> uid==user  id   即用户在系统的身份证号
>
> gid==group id  即用户的户口本号码

| ------- | --------------- | ------------------------------------------------------------ |

|         | -M              | 没有家目录                                                   |
|         | -g  2026        | 指定组id；可以用，但是，这个用户组，必许提前查询在           |
|         | -G root         | 指定“附属组”                                                 |

# 六、别名

> 设么是别名？
>
> 一个命令如果太长，我们可以给他起个小名，增加生产效率

````bash
#1，查看别名
[root@K-oldboy26 ~ 11:25:05]# alias 
alias cp='cp -i'
alias l.='ls -d .* --color=auto'
alias ll='ls -l --color=auto'
alias ls='ls --color=auto'
alias mv='mv -i'
alias rm='rm -i'

#2，设置别名（想要永久生效，写入到开机自动执行文件中或者变量文件中）
[root@K-oldboy26 ~ 15:25:34]# alias vimwangka="vim /etc/sysconfig/network-scripts/ifcfg-ens33" 
[root@K-oldboy26 ~ 15:49:26]# alias 
alias cp='cp -i'
alias l.='ls -d .* --color=auto'
alias ll='ls -l --color=auto'
alias ls='ls --color=auto'
alias mv='mv -i'
alias rm='rm -i'
alias vimwangka='vim /etc/sysconfig/network-scripts/ifcfg-ens33'
[root@K-oldboy26 ~ 15:49:30]# vimwangka
````
